目标：混合信息流与萌系视觉、本地写作工作台、共用内容发布核心及 CLI/MCP。公开站点仍为纯静态。

- [x] 混合首页按发布时间排序，碎碎念全文，静态分页，保留独立列表。
- [x] 原创插画与圆润细节，桌面/手机及明暗截图完成复查。
- [x] 内容核心：稳定路径 ID、草稿默认、revision 并发检查、requestId 幂等、图片导入。

- [x] 发布状态机：模拟与真实模式分离、目标授权配置、Git 与 Actions 状态；真实远程执行保留至授权目标明确后。
- [x] 回归类型、浏览器、草稿资源隔离、根路径及子路径。
- [x] 中文教程、Hermes 示例、故障排查、最终证据。

## 设计决策与边界

- 项目当前不是 Git 仓库；不自动初始化或关联远程，不执行真实推送。
- CLI、本地 HTTP 工作台和 MCP 共用 Node 内容核心；工作台只监听回环地址。
- 发布先在隔离副本构建检查；模拟不改变正式源文件发布状态，不声称已上线。
- Hermes 安装信息未提供，先实现标准 stdio MCP 与独立 CLI，主机专用配置作为待适配项。
- GPT-6 Luna（max）只承担列表静态分页等明确任务，主代理负责复杂逻辑与验收。

## 当前进度

授权的本地开发范围已完成。16 项工具测试、2 项工作台浏览器测试、52 项网站双路径浏览器测试全部通过，类型检查无错误/警告/提示。草稿专用图片发布后撤回的独立构建检查也通过。保留根路径最终 dist，正式源内容未增加测试文章。

后续需要用户信息的事项：远程仓库/分支/域名与首次发布授权；Hermes 的实际版本和配置位置。它们不以模拟结果冒充已完成联调。本轮没有执行远程推送、公开部署或创建后台常驻监视服务。
