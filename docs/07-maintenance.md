# 维护、排错与后续扩展

## 每次内容更新

编辑 Markdown → dev 预览 → check → build → verify → commit / push。只有改了页面行为或布局才需要跑相应浏览器测试；纯文字修改不必反复跑全部 UI 测试。测试输出及截图是验收证据，不是网站内容，不放进 public。

## 更改主题或组件

先改一个页面作为样本，检查桌面和手机。改变 global.css 变量会影响全站；改变 Base 会影响导航、SEO 和主题。要同时检查暗色，否则新增的白色背景可能在夜间刺眼。不要仅看首页：文章的代码、公式、表格才是排版压力较大的内容。

站内地址使用 url()；标签用 tagUrl()，内容用 entryUrl()。新增 JSON、订阅源或列表必须从 published() 读取。不要直接将整个内容目录复制到 public。

## 升级依赖

先保存当前工作，然后一次升级一组依赖。阅读 Astro 官方迁移指南，特别注意内容 API、Markdown 处理器和资源路径。升级后执行 check、build、verify 以及浏览器测试，再测试一次子路径和草稿撤回场景。package.json 与 lockfile 一起提交，CI 使用 npm ci。

## 常见问题

| 现象                | 原因与处理                                                                        |
| ------------------- | --------------------------------------------------------------------------------- |
| npm.ps1 被拦截      | PowerShell 改用 npm.cmd；不必修改全局执行策略                                     |
| 草稿没出现在页面    | 在 `npm run dev` 中打开 `/drafts/`；无需为预览临时改成 `draft: false`             |
| 已发布文件没出现    | 检查 `draft: false` 和终端字段校验错误；`preview` 需要重新 build                  |
| 文件名报错          | 使用英文小写、数字、连字符；文件夹也遵循同一规则                                  |
| 公式显示为普通文字  | 检查 `$` 是否成对，以及 unified、remark-math、rehype-katex 配置                   |
| 图片 404            | 公开资源路径不含 public；src 图片引用相对 Markdown 文件，注意大小写               |
| 搜索没有最新内容    | 搜索只包含已发布内容；草稿请在 dev 的 `/drafts/` 预览，已发布内容则重建索引并刷新 |
| 搜索网络失败        | 确认 search-index.json 地址含 base 且托管服务器可读取                             |
| 暗色重载后恢复      | 浏览器可能阻止 localStorage；当前页切换仍有效                                     |
| verify 提示草稿泄露 | 不要忽略或跳过；检查是否放进 public，或新增出口绕过过滤                           |
| 4321 被占用         | 关闭自己的预览进程，或为开发服务选择另一个端口；测试需空闲 4321                   |

## 本地写作工具

本地写作台、CLI 与 MCP 已实现，并共用同一套内容与发布核心。它们读取和写入现有 Markdown 文件，不另建内容数据库；写作台支持编辑、图片导入、保存预览和检查，CLI/MCP 提供相同操作的自动化入口。新手操作见[写作台与 Agent 指南](13-writing-and-agents.md)，架构与实现边界见[开发工作坊](14-development-workshop.md)。

凭据由 GitHub CLI 和 Git 自身的本机认证管理，不放入项目配置。内容 ID 是稳定标识，修改标题时不要顺便改 URL。远程发布需要用户确认目标并配置；本地工具与发布能力的存在不代表已部署到线上。

## 当前边界

- 不提供评论、点赞、访客登录或线上后台。写作台仅在本机运行；Markdown 仍是内容源文件。
- 搜索是浏览器端子串搜索，没有拼音、语义匹配或搜索结果分页；内容很大时再考虑分片索引。
- 首页混合信息流、文章列表和碎碎念列表均采用静态分页，每页 6 条；第一页保留原路径，后续页在构建时生成。
- 项目已实现标准 MCP stdio 服务；具体 Hermes 版本与专用配置尚未确认，不能据此称为原生集成，见[操作指南](13-writing-and-agents.md)。
- 远程发布路径已有授权和工作区检查，但真实目标配置仍需用户确认；没有配置或完成实际部署时，不能声称已上线。失败后先核对任务、提交和 Actions，不盲目重试。
- RSS 提供文章摘要和动态摘要，不是完整正文订阅。
- `npm run dev` 提供本机草稿箱 `/drafts/` 和带草稿标记的详情预览；首页、标签、归档、搜索、RSS、sitemap、生产构建及 `npm run preview` 仍只包含已发布内容。
- src 内容由站主编写，Markdown 可包含 HTML；不支持让访客提交不受信任的 Markdown。
- 本期浏览器验收使用 Chromium 桌面与手机模拟，不代表已在所有真机、Safari 和读屏软件上测试。
- 自定义域名、真实 GitHub Actions 执行与公网部署需在用户确认目标后实际验证，操作边界见[开发工作坊](14-development-workshop.md)。

这些边界说明当前功能的适用范围，也为后续扩展留下清楚的切入点。
