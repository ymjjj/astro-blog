# 第一阶段需求基线、实施计划与验收

本文件记录第一阶段的需求基线与验收结果，不代表后续迭代后的完整现状。当前范围和新增功能请以 [12-progress.md](12-progress.md)、[13-writing-and-agents.md](13-writing-and-agents.md) 和 [14-development-workshop.md](14-development-workshop.md) 为准；最新阶段的验收证据见 [15-validation.md](15-validation.md)。本项目是独立的静态个人博客，源码位于 `D:\projects\astro-blog`，不修改旧博客；第一阶段以本地验收和可部署配置为终点，不创建远程仓库或公开发布。

## 范围

- Astro 静态输出；Markdown 长文章与无标题短动态，独立链接、日期、标签、图片。
- 首页、文章列表与详情、动态时间线与详情、标签索引与详情、归档、关于、404。
- 目录、代码高亮、数学公式、中文搜索、明暗主题、RSS、SEO、移动端和键盘访问。
- 草稿不得进入任何公开构建产物；统一内容模型，为后续本地编辑器保留接口。
- 示例、写作模板、GitHub Actions / Pages 配置和完整中文学习文档。
- 不做账号、评论、点赞、可视化编辑器；不虚构作者经历。

## 实施顺序

1. 确认数据模型、路径规则与视觉方案，建立需求及决策文档。
2. 实现布局、文章与动态渲染、列表、主题及搜索。
3. 添加示例、模板、插画、RSS / SEO / 部署配置。
4. 检查类型、构建、生产产物、浏览器行为、手机布局与子路径。
5. 按教程实际添加内容并构建，保存截图、结果和逐项验收证据。
