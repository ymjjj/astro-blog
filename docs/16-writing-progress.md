## 设计决定

- `.blog/history` 保存已保存版本，正文及元数据以源文件哈希标识；相同版本不重复存储。恢复保留当前发布状态。
- `.blog/recovery` 保存未完成表单，与 src/content 分开，不参加 Astro 内容收集。浏览器本地副本补足关闭页面前的防抖窗口。
- 所有写入口使用共用核心校验、项目锁和 revision/requestId；直接外部编辑器不受项目锁管理，保存前再次检查源版本。建议避免第三方同时写同一文件。
- 不增加公开站点依赖，不执行真实发布。

## 本轮发现与修复

1. 自动保存仍在刷新列表时，用户后续操作被忙碌标记忽略：改为等待自动保存结束再执行导图/预览等动作。
2. 自动保存中继续输入：以编辑序号与请求内容核对，更新版本信息但不替换编辑框，后续输入继续保存。
3. 断网时 checkpoint 可能已成功但响应丢失：副本版本冲突时另建会话，不覆盖原副本；创建请求保存原 requestId 以便幂等恢复。
4. 手机预览回归的 iframe 稳定性等待：先滚动外层预览框，再滚动内部图片并检查解码成功，避免跨 frame 滚动等待挂起。
5. 新测试的 Page 类型导入：修正为 type-only，类型检查随后通过（70 个文件，零错误/警告/提示）。
